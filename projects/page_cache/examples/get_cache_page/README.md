# Get Cache Page Example

This example demonstrates how a kernel module can open a file, access its page-cache mapping, locate a page in the page cache, and obtain the page's physical frame number (PFN).

The example uses:

* `filp_open()` to open a file from kernel space
* `file_inode(file)->i_mapping` to obtain the file's `address_space`
* `find_get_page()` to find a page in the page cache
* `page_to_pfn()` to obtain the page's physical frame number
* `put_page()` to release the page reference
* `filp_close()` to close the file

## Files

```text
get_cache_page.c    Kernel module
Makefile            Build configuration
data.bin            Test file, generated by the Makefile
```

The Makefile creates `data.bin` as a single 4096-byte page.

## Build

Run:

```bash
make
```

This builds the kernel module and creates `data.bin`:

```text
get_cache_page.ko
data.bin
```

## Run

The module looks for `data.bin` in the current directory. Before loading the module, access the file from user space:

```bash
cat data.bin > /dev/null
```

This causes the file's first page to be brought into the page cache.

Then load the kernel module:

```bash
sudo insmod get_cache_page.ko
```

View the kernel output:

```bash
sudo dmesg | tail
```

You should see output similar to:

```text
get_cache_page:
  file            = data.bin
  file offset     = 0
  page index      = 0
  PFN             = 1533198
  physical addr   = 0x17650e000
```

The exact PFN and physical address will vary between systems and executions.

Unload the module:

```bash
sudo rmmod get_cache_page
```

## How It Works

The module first opens the file:

```c
file = filp_open(filename, O_RDONLY | O_LARGEFILE, 0);
```

It then obtains the file's `address_space`:

```c
mapping = file_inode(file)->i_mapping;
```

The `address_space` represents the mapping between the file and its page-cache pages.

The module searches for the page at file page index 0:

```c
page = find_get_page(mapping, 0);
```

Because the page size is 4096 bytes, page index 0 corresponds to file offset 0.

If the page is found, the module obtains its physical frame number:

```c
pfn = page_to_pfn(page);
```

The PFN can be converted to a physical address by shifting it left by `PAGE_SHIFT`:

```c
pfn << PAGE_SHIFT
```

Finally, the references acquired by the module are released:

```c
put_page(page);
filp_close(file, NULL);
```

## Important Note

`find_get_page()` **does not read the file into the page cache**. It only searches for a page that is already present.

Therefore, the example first accesses the file from user space:

```bash
cat data.bin > /dev/null
```

This ensures that the first page of `data.bin` is already in the page cache when the kernel module calls `find_get_page()`.

If the page is not present, `find_get_page()` returns `NULL`, and the module reports:

```text
get_cache_page: page is NOT in page cache
```

## Cleanup

Remove the kernel module and generated test file:

```bash
sudo rmmod get_cache_page
make clean
```
